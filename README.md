# Auction Mart

An ASP.NET Web Forms school project for an online auction site. The solution contains separate pages for administrative tasks, product uploads, subscriptions, and checkout.

## Explore the code

- [Visual Studio solution](Auction%20Mart.sln)
- [Checkout code-behind](Auction%20Mart/forms/CheckOut.aspx.cs)
- [Administration code-behind](Auction%20Mart/forms/Admin.aspx.cs)

## Open locally

Use Visual Studio on Windows with ASP.NET web development tools and the .NET Framework 4.7.2 targeting pack. Open the solution and restore its packages. Review the application configuration and any database dependencies before trying the workflows with local test data.
